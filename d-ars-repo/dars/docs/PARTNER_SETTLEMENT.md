# 파트너 정산 리포트 (제이투모로우원 — 수익 배분 산출 근거)

작성 2026-09-16. 정본: 로직 `lib/settlement.js` · API `app/api/admin/settlement/route.js` · 테스트 `tests/settlement.test.mjs`.
전제 구조는 `docs/PARTNER_CHANNEL.md`(파트너·고객사·귀속 이력).

## 무엇을 내놓나

관리자 전용 `GET /api/admin/settlement?month=YYYY-MM[&format=csv]` — 정산월 기준으로 **파트너별 → 고객사별** 한 줄씩:
계약일 · 세션수 · 청구액(원) · 수수료율(%) · 수수료(원) · 산출상태 · **귀속 근거**(이력 id · 기록일 · 담당 표시명 · 근거 문구) · 산식.
CSV 는 같은 줄을 평탄화한 것이며(BOM · 수식 인젝션 방지 · `lib/export` 규약), 파트너 합계 행은 넣지 않는다 —
스프레드시트에서 합계는 사용자가 다시 계산할 수 있어야 검증이 된다.

## 규칙(코드가 강제한다)

- **귀속은 이력이 정본.** `organizations.partner_id`(현재 상태)가 아니라 `partner_attributions` 중 **정산월 말일 기준 최신 행**으로
  판정한다(`attributionAsOf`). 다음 달에 기록된 정정은 지난 달 정산에 소급하지 않는다. 이력이 없는 고객사는 어느 파트너에도
  넣지 않고 `unattributed`(`ATTRIBUTION_MISSING`) 로 따로 보고한다 — 근거 없는 정산 금지.
- **수수료율은 설정값에서만.** 환경변수 `PARTNER_COMMISSION_RATES`(JSON · 퍼센트 · 키는 파트너 id 또는 기본율 `*`).
  코드에 율 숫자를 두지 않으며 테스트가 감시한다. 미설정이면 수수료를 0 으로 꾸미지 않고 `null` + `rate_missing`.
  설정 오류는 항목 단위로만 버리고(`rateProblems` 로 보고 · 값 원문 미포함) 나머지 정산을 막지 않는다.
- **산식**: 수수료 = 청구액(원) × 수수료율(%) ÷ 100 · 원 미만 반올림(half-up). 정수 연산만 쓴다(부동소수 오차 없음).
  율은 소수 둘째 자리(1/100 %)까지, 청구액은 0 이상 정수(원).
- **산출상태**(줄 단위 · `complete` 만 합계에 들어간다): `complete` · `rate_missing`(율 없음) · `amount_missing`(청구액 없음) ·
  `amount_invalid`(청구액 형식 이상). 청구액 없음이 율 없음보다 먼저 드러난다(율을 넣어도 금액이 없으면 못 낸다는 뜻).
- **개인정보 없음.** 파트너·고객사 **법인명**과 운영자 표시명만 화이트리스트로 통과시키고, 입력에 섞인 그 외 컬럼은 버린다.
- **저장·전송 없음.** GET 전용. 리포트는 매번 계산한다.

## 지금 상태와 한계(정직하게)

- **이용 실적(세션수·청구액)의 원천이 아직 없다.** `visual_sessions` 는 고객사(`org_id`)와 연결돼 있지 않고 과금 원장도 없다.
  라우트는 `usageSource:'none'` 으로 이를 드러내고, 모든 줄이 `amount_missing` 으로 남는다. `buildSettlement` 는 이미
  `usage: [{ org_id, month, sessions, amount_krw }]` 입력을 받으므로 원장이 생기면 그 한 줄만 배선한다 — 과금 원장 연결과
  청구액 기준(세션 단가·정액 등)은 계약서 확정 후 **[승인 필요]**.
- 운영 DB 에 `db/partner.sql` 이 적용되지 않았으므로 라이브 라우트는 `source:'db'|'none'` 과 함께 **파트너 0 의 빈 리포트**를
  돌려준다(오류가 아니라 빈 상태). 적용은 사람이 한다 **[승인 필요]**.
- `PARTNER_COMMISSION_RATES` 실값(계약서 확정 수수료율) 주입은 **[승인 필요]**. 어느 프로필에서도 자동화가 넣지 않는다.
- 화면(`/admin/settlement`)은 아직 없다 — API·CSV 로 조회·내보내기가 되며 화면은 후속 항목.
- 세금계산서·정산 확정·지급은 이 리포트의 범위 밖이다(리포트는 **산출 근거** 문서다).
